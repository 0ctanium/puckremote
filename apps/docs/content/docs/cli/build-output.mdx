`artifactVersion` in the manifest is your package version plus the first 12 hex characters of the
bundle hash, e.g. `1.1.0+3fa9c2d81b04`.

The host re-validates everything in the manifest with its own schema: the CLI's checks exist to
give you early, precise errors. See [Manifest format](/docs/sdk/manifest).
