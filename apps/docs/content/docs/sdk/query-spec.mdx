---
title: Query spec
description: The JSON query language blocks use, as the host validates it.
---

```ts
type QuerySpec =
  | { source: 'host'; op: 'find'; collection: string;
      args: { where?, limit?: int | ParamRef, sort?: '-?field', select?: string[], depth?: int, page?: int | ParamRef } }
  | { source: 'host'; op: 'findByID'; collection: string; id: string | ParamRef; args: { select?, depth? } }
  | { source: 'host'; op: 'global'; slug: string }
  | { source: 'adapter'; adapter: string; op: string; params: Record<string, ParamValue> }
  | { source: 'http'; origin: string; path: '/…'; method: 'GET' | 'POST';
      params: Record<string, ParamValue>; headers: Record<string, string | { $secret: 'NAME' }> }
```

## `where`

```ts
type Where = { and: Where[] } | { or: Where[] } | { [field]: Condition }
type Condition = { equals: P } | { in: P[] | ParamRef } | { contains: P } | { gt: P } | { lt: P }
```

`P` is a JSON primitive or a `ParamRef`. Each field's allowed operators come from the collection
policy (default: all; `filter: false`: none).

## Param refs

`{ $prop }`, `{ $page: 'slug' | 'locale' }`, `{ $site: 'locale' | 'name' }`, `{ $query }` (≤ 64-char
name, value cut at 256 chars), and `{ $secret }` in headers only. See
[declarative data](/docs/concepts/declarative-data).

## Adapter requests

`toRequest` must return `{ method: 'GET' | 'POST', path: '/…' (≤ 2048), params?, headers? }`.
GET params become the query string (arrays repeated, objects JSON-encoded); POST params become a
JSON body. Forbidden headers: `host`, `cookie`, `authorization-proxy`, `connection`,
`transfer-encoding`, `content-length`.
