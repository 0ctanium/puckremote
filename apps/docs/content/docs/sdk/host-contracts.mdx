---
title: Host contracts
description: The interfaces in @puck-remote/sdk/host that host adapters implement.
---

`@puck-remote/sdk/host` holds the contracts for **trusted** plugins that run on the host. They live
in the SDK (not the engine) so adapter packages stay light.

```ts
import type { ArtifactStore, DataSource, Theme } from '@puck-remote/sdk/host';
import { defineCollection, defineDataSource, defineGlobal } from '@puck-remote/sdk/host';
```

| Contract | Guide |
|---|---|
| `DataSource`, `CollectionDef`, `GlobalDef`, `SourceContext`, `SourceContextBase` | [Data source](/docs/core/adapters/data-source) |
| `ArtifactStore`, `FileChanges`, `Theme`, `ThemeRole`, `THEME_ROLES`, `ThemeList`, `ThemeConflictError` | [Artifact store](/docs/core/adapters/artifact-store), [Themes](/docs/concepts/themes) |
| `AuthorizeApi`, `ApiAction` | [HTTP API › Artifacts API](/docs/http-api#artifacts-api) |

## Type helpers

`CollectionName<S>`, `GlobalName<S>`, `DocOf<S, K>`, `GlobalDocOf<S, K>` extract names and
document types from a data source type. The theme query builders use them, which is how
[typed queries](/docs/guides/typing-queries) work.
