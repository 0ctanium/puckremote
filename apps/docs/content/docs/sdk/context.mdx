---
title: Render context
description: "The ctx argument of render: request information, template params and asset URLs."
---

```tsx
render: (props, data, ctx) => {
  ctx.assets.style(ctx.assetUrl('theme.css'));
  ctx.assets.script(ctx.assetUrl('enhance.js'), { defer: true });
  return <img src={ctx.assetUrl('logo.svg')} alt="" />;
}
```

Effects (`assets.*`) are limited to 64 per render and 2 KB per string. Script and style
URLs must be your own assets, or https URLs whose origin the host allowlisted (others are
dropped).

There is no `ctx.head`: page metadata (title, description) is built by the app from the
template's root props ([D-0370](/docs/internal/decisions#D-0370)).
