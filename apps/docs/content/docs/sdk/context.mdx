---
title: Render context
description: "The ctx argument of render: request information, asset URLs and head effects."
---

```tsx
render: (props, data, ctx) => {
  ctx.head.title(`${props.title} · ${ctx.site.name}`);
  ctx.head.meta('description', props.summary);
  ctx.assets.style(ctx.assetUrl('theme.css'));
  ctx.assets.script(ctx.assetUrl('enhance.js'), { defer: true });
  return <img src={ctx.assetUrl('logo.svg')} alt="" />;
}
```

Effects (`assets.*`, `head.*`) are limited to 64 per render and 2 KB per string. Script and style
URLs must be your own assets, or https URLs whose origin the host allowlisted (others are
dropped).
