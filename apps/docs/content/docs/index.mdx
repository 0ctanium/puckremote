## What it is

puck-remote is a self-hosted library that connects three parties:

| Party | Trust | What they provide |
|---|---|---|
| **Theme developers** | Untrusted ([D-0052](/decisions#D-0052)) | React blocks written with `defineBlock(...)`, built by the CLI into a versioned **artifact** |
| **The host operator** | Trusted | A Next.js (or other) app wired with adapters: data source, page store, artifact store, cache, auth |
| **Editors** | Authenticated | Pages composed in the [Puck](https://puckeditor.com) editor from the theme's blocks |

The central claim, validated by the POC and hardened in M1 and M2:

> Untrusted React drives both the Puck editor and a server-rendered public site, and developer code
> only ever executes inside `isolated-vm`, inside a permission-restricted worker process.

## How it works, in one picture

```
theme repo ──puck-remote build──▶ manifest.json + bundle.js + assets ──publish──▶ ArtifactStore
                                                                                     │
                     ┌───────────────────────────────────────────────────────────────┘
                     ▼
 host app ─ @puck-remote/next ─ @puck-remote/core
                                 ├─ ArtifactLoader: verify hashes + zod-validate manifest, swap versions
                                 ├─ Query resolver: runs the blocks' declarative queries (DataSource, HTTP, adapters)
                                 ├─ RenderRuntime: worker pool → isolated-vm → bundle.__render(...) → HTML string
                                 └─ Puck RSC <Render>: parses HTML, swaps nonce-checked slot markers
```

- The host **never builds** theme code, and never runs it outside the isolate.
- Blocks are **declarative about data**: they describe queries as JSON, and the host runs them
  (validated, deduped, budgeted, cached). Blocks never do I/O.
- Block output is an **HTML string** with nonce-protected slot markers. The host turns it into
  React and swaps the markers for real Puck slots.
- The **editor** is built from the manifest's JSON only. Blocks in the editor canvas are rendered
  **on the server** by the same pipeline; the theme bundle is never sent to a browser
  ([D-0080](/decisions#D-0080)).
