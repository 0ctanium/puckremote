title: Theme development

A theme is a small package (see `examples/theme`) that depends on `@puck-remote/sdk` and React,
with `@puck-remote/cli` as a dev dependency.

```
blocks/<slug>.tsx       one block per file, default export defineBlock(...)  (lowercase slug names)
root.tsx                optional page frame, defineRoot(...)
adapters/*.ts           optional sans-IO adapters, defineAdapter(...)
config/categories.ts    optional editor categories, defineCategories(...)
assets/**               copied as-is (CSS, client scripts, images)
puck-remote-env.d.ts    optional: register the host data source type
```

## A block

```tsx
import { defineBlock, find, Slot } from '@puck-remote/sdk'

export default defineBlock({
  label: 'Latest posts',
  category: 'Content',
  fields: {
    heading: { type: 'text' },
    count: { type: 'number', min: 1, max: 12 },
    layout: { type: 'select', options: [{ label: 'List', value: 'list' }, { label: 'Grid', value: 'grid' }] },
    columns: { type: 'number', visibleIf: { field: 'layout', eq: 'grid' } },
    content: { type: 'slot' },
  },
  defaultProps: { heading: 'Latest', count: 3, layout: 'list' },
  data: {
    posts: find('posts', {
      limit: { $prop: 'count' },
      sort: '-publishedAt',
      select: ['title', 'slug'],
      where: { status: { equals: 'published' } },
    }),
  },
  render: (props, data, ctx) => (
    <section>
      <h2>{props.heading}</h2>
      {data.posts.ok ? data.posts.data.docs.map((p) => <h3 key={p.slug}>{p.title}</h3>) : <p>Unavailable</p>}
      <Slot name="content" />
    </section>
  ),
})
```

### Rules the build enforces

- Everything except `render` must be plain JSON (no functions, class instances, Dates, Maps,
  symbols, `undefined` in arrays, non-finite numbers).
- Forbidden keys: `permissions`, `resolvePermissions`, `resolveFields`, `resolveData`, `inline`
  ([D-0006](/decisions#D-0006)).
- Block names are lowercase slugs; names starting with `__` are reserved.
- `render` must be synchronous and pure. It cannot fetch, set timers or keep state.

## Fields

| Type | Value | Options |
|---|---|---|
| `text`, `textarea` | string | `placeholder` |
| `number` | number | `min`, `max`, `step` |
| `select`, `radio` | option value | `options: [{ label, value }]` |
| `array` | item objects | `arrayFields`, `itemSummary` (sub-field name), `defaultItemProps`, `min`, `max` |
| `object` | object | `objectFields` |
| `slot` | (rendered with `<Slot>`) | `allow`, `disallow`; top level only |
| `host:color` | string | host-owned UI |
| `host:media` | `{ url, alt? }` | host-owned UI |
| `host:link` | `{ href, label?, newTab? }` | host-owned UI |

Every field also accepts `label` and `visibleIf`.

### `visibleIf`

Data only: `{ field, eq }`, `{ field, in: [...] }`, `{ field, not }`, `{ and: [...] }`,
`{ or: [...] }`. The host evaluates it as a Puck `resolveFields` on top-level fields.

## Data

See [declarative data](/docs/concepts/declarative-data). Always handle `ok: false`; in the editor,
data is `{ ok: false, error: 'loading' }` until it arrives.

## `ctx`

| Member | Meaning |
|---|---|
| `isEditing`, `locale`, `nonce`, `page.slug`, `site.name` | Request context |
| `assetUrl(path)` | `/theme/v<N>/assets/<path>`; traversal, `?`, `#` and schemes are rejected |
| `assets.script(url, { defer, async, module })` | Adds a `<script>` (site only, never the editor canvas) |
| `assets.style(url)` | Adds a stylesheet (site and editor canvas) |
| `head.title(t)`, `head.meta(name, content)` | Page metadata; first title wins |

Script and style URLs must be this artifact's assets, or https URLs whose origin the host
allowlisted in `security.scriptOrigins` / `styleOrigins`; others are dropped.

## Root

```tsx
import { defineRoot, global, Slot } from '@puck-remote/sdk'

export default defineRoot({
  fields: { title: { type: 'text', label: 'Page title' } },
  defaultProps: { title: 'Untitled page' },
  data: { site: global('site') },
  render: (props, data, ctx) => {
    ctx.head.title(`${props.title} · ${ctx.site.name}`)
    ctx.assets.style(ctx.assetUrl('theme.css'))
    return <main><Slot name="children" /></main>
  },
})
```

## Adapters (sans-IO)

```ts
import { defineAdapter } from '@puck-remote/sdk'

export default defineAdapter({
  name: 'events',
  origin: 'https://api.example.com',
  toRequest(q) {
    return { method: 'GET', path: '/v1/events', params: { limit: Number(q.params.limit ?? 5) },
             headers: { 'x-api-key': { $secret: 'EVENTS_API_KEY' } } }
  },
  fromResponse(json) {
    return (json as { items: { uid: string; name: string }[] }).items.map((e) => ({ id: e.uid, title: e.name }))
  },
})
```

Use it from a block with `query('events', 'upcoming', { limit: { $prop: 'count' } })`. The host
must allowlist the origin (`http.allowedOrigins`) and bind the secret to it (`secrets`).

## Build and publish

```bash
puck-remote build
```

```bash
puck-remote publish --artifacts ../../artifacts
```

See the [CLI reference](/docs/reference/cli). Build errors name the file and key at fault.
