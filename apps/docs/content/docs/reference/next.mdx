## `createPuckRemote(config, { loginUrl? })`

| Member | Behavior |
|---|---|
| `loadPage(props, context?)` | Normalizes the slug, takes the first value of each search param, calls `preparePage` (memoized per request with React `cache()`, so `generateMetadata` and the page share one isolate pass), adds the `x-nonce` as `scriptNonce`. `notFound()` on unknown pages or wrong origin |
| `generateMetadata(props)` | `pageMetadata(await loadPage(props))` |
| `loadEditor({ params })` | Rebuilds a standard `Request` from `headers()`, calls `core.loadEditor`. Wrong surface or 403 → `notFound()`; 401 → redirect to `loginUrl?next=<path>` if set, else `notFound()` |
| `api` | `{ GET, POST }` → `core.handleApi` |
| `theme` | `{ GET, HEAD }` → `core.handleTheme` |
| `core` | The underlying `PuckRemoteCore` |

## `createProxy(config)`

For every matched request:

1. Classify the surface by path and origin; **404** if this origin doesn't serve it.
2. Generate a CSP nonce, compute `securityHeaders(surface, …)`, pass `x-nonce` and the CSP to Next
   through request headers (Next reads the nonce from the request's CSP header), and set the
   response headers.
3. For the site surface, compute `pageCacheability`: `x-page-cacheable: true`, or `false` plus
   `cache-control: no-store` and `x-uncacheable-blocks`.

It imports only `@puck-remote/core/edge` and `/config`, never isolated-vm.

## `withPuckRemote(nextConfig)`

Adds `isolated-vm` and `@puck-remote/core` to `serverExternalPackages`.
