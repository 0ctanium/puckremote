```ts title="puck-remote.config.ts"
import { defineConfig } from '@puck-remote/core/config';

export default defineConfig({
  artifacts, source, pages, // required adapters
  // everything else is optional
});
```

`defineConfig` is a typed identity function from `@puck-remote/core/config`, which never loads the
sandbox. The proxy and your app can therefore import the config file safely. Defaults are applied
when the engine starts, together with the [production guards](#production-guards).

## Production guards

With `NODE_ENV=production`, the engine refuses to start when:

- `auth` is missing;
- `origins` is missing (unless `allowSharedOrigin`);
- an origin is both a site and an editor origin (unless `allowSharedOrigin`);
- `origins.editor` is empty;
- `preview.secret` is shorter than 32 bytes.

`preview.ttlSeconds` outside 60–2592000 is rejected in every environment.

`devAllowAll()` itself throws in production.
