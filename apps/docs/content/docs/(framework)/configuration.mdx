```ts title="puck-remote.config.ts"
import { defineConfig } from '@puck-remote/core/config';

export default defineConfig({
  artifacts, source, // required adapters
  // everything else is optional
});
```

`defineConfig` is a typed identity function from `@puck-remote/core/config`, which never loads the
sandbox. The proxy and your app can therefore import the config file safely. Defaults are applied
when the engine starts, together with the [checks](#checks).

## Checks

The engine refuses a config where:

- `origins.host` is empty;
- `origins.editor` is also a host origin.

There is no `auth` option: the core has no authority of its own. Your app authenticates its admin
pages, RPC handlers and publishing actions with its own session.
