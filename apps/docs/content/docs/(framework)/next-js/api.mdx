## `<PuckRemotePage page />`

Server component. Emits the theme's stylesheets (hoisted into `<head>`), the page rendered by
Puck's RSC renderer, and theme scripts carrying the CSP nonce.

<TypeTable type={{ page: { description: "The result of remote.loadPage().", type: 'PreparedPage', required: true } }} />

## `createProxy(config)`

<TypeTable
  type={{
    config: {
      description: "The same config object. Only artifacts, origins and security are read.",
      type: 'PuckRemoteConfig',
      required: true,
    },
  }}
/>

For each request the proxy:

1. sets [security headers](/docs/security-headers) with a fresh CSP nonce and hands the nonce to
   Next: the admin policy on admin origins (frames only the editor origin), the site policy
   elsewhere;
2. on public pages, sets `x-page-cacheable: true`, or `false` with `cache-control: no-store` and
   `x-uncacheable-blocks` when a block reads URL query parameters.
