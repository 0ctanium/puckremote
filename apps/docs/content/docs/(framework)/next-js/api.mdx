### `LoadTemplateOptions`

<TypeTable
  type={{
    params: { description: "Page-specific data (e.g. { handle }), read by `$params` refs and `ctx.params`. At most 32 string values of up to 1 KB.", type: 'Record<string, string>' },
    searchParams: { description: "The page's searchParams, read by `$query` refs (first value of each key).", type: 'Promise<Record<string, string | string[] | undefined>>' },

Your route picks the template ([D-0371](/docs/internal/decisions#D-0371)) and builds its
metadata from the template's root props ([D-0370](/docs/internal/decisions#D-0370)):

```tsx title="app/products/[handle]/page.tsx"
import { PuckRemoteTemplate } from '@puck-remote/next';
import type { Metadata } from 'next';
import { remote } from '@/puck-remote';

type Props = { params: Promise<{ handle: string }> };

const load = async ({ params }: Props) =>
  remote.loadTemplate('product', { params: { handle: (await params).handle } });

export async function generateMetadata(props: Props): Promise<Metadata> {
  const { title } = (await load(props)).data.root.props ?? {};
  return { title: typeof title === 'string' ? title : undefined };
}

export default async function Page(props: Props) {
  return <PuckRemoteTemplate template={await load(props)} />;
}
```

## `createProxy(config, options?)`

<TypeTable
  type={{
    config: {
      description: "The same config object. Only artifacts, origins, routes and security are read.",
      type: 'PuckRemoteConfig',
      required: true,
    },
    'options.template': {
      description: "The template a public path renders, for its cache headers. Use the same mapping as your routes. Without it no cache headers are set.",
      type: '(pathname: string) => { name: string } | null',
    },
  }}
/>

For each request the proxy:

1. lets Next's own files (`/_next/*`) through untouched;
2. on `origins.editor`, rewrites `/` to `routes.editor` (your editor page) with the
   [editor's headers](/docs/security-headers#editor) and a fresh CSP nonce. Every other path,
   `routes.editor` itself included, answers 404 ([D-0282](/docs/internal/decisions#D-0282));
3. on `origins.host`, rewrites every path under `routes.admin` (`/x` → `/admin/x`, `/` →
   `/admin`), except the theme route, which the editor loads from there. Old links already under
   the prefix (`/admin`, `/admin/x`) get a 307 redirect to `/` or `/x`, query string kept
   ([D-0307](/docs/internal/decisions#D-0307));
4. on other origins, answers 404 for `routes.editor/**`, and for `routes.admin/**` when `origins`
   is configured;
5. sets [security headers](/docs/security-headers) with a fresh CSP nonce and hands the nonce to
   Next: the admin policy on `origins.host` (frames only the editor origin), the site policy
   elsewhere;
6. on public pages that `options.template` maps to a template, sets `x-template-cacheable: true`,
   or `false` with `cache-control: no-store` and `x-uncacheable-blocks` when a block reads URL
   query parameters ([D-0389](/docs/internal/decisions#D-0389)).
