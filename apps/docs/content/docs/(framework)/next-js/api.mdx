## `<PuckRemotePage page />`

Puck's RSC renderer, and theme scripts carrying the CSP nonce.

## `createProxy(config)`

<TypeTable
  type={{
    config: {
      description: "The same config object. Only artifacts, origins, routes and security are read.",
      type: 'PuckRemoteConfig',
      required: true,
    },
  }}
/>

For each request the proxy:

1. on `origins.editor`, rewrites every path to `routes.editor` + path (your editor page) with the
   [editor's headers](/docs/security-headers#editor) and a fresh CSP nonce, and stops there; on
   other origins, `routes.editor/**` answers 404;
2. sets [security headers](/docs/security-headers) with a fresh CSP nonce and hands the nonce to
   Next: the admin policy on `origins.host` (frames only the editor origin), the site policy
   elsewhere;
3. on public pages, sets `x-page-cacheable: true`, or `false` with `cache-control: no-store` and
   `x-uncacheable-blocks` when a block reads URL query parameters.
