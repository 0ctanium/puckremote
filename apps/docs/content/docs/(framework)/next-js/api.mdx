## `<PuckRemotePage page />`

Server component. Emits the theme's stylesheets (hoisted into `<head>`), the page rendered by
Puck's RSC renderer, and theme scripts carrying the CSP nonce.

## `<EditorClient {...props} />`

Client component: the Puck editor. Pass the result of `remote.loadEditor()` unchanged.

## `createProxy(config)`

<TypeTable
  type={{
    config: {
      description: "The same config object. Only artifacts, pages, routes, origins, allowSharedOrigin and security are read.",
      type: 'PuckRemoteConfig',
      required: true,
    },
  }}
/>

For each request the proxy:

1. answers **404** if the request's origin doesn't serve that surface (site, editor, API, theme);
2. sets [security headers](/docs/security-headers) with a fresh CSP nonce and hands the nonce to
   Next;
3. on public pages, sets `x-page-cacheable: true`, or `false` with `cache-control: no-store` and
   `x-uncacheable-blocks` when a block reads URL query parameters.

## `withPuckRemote(nextConfig?)`

Returns your Next config with `isolated-vm` and `@puck-remote/core` added to
`serverExternalPackages`.
