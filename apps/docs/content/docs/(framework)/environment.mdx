## Packages

| Variable | Read by | Effect |
|---|---|---|
| `NODE_ENV` | core | `production` disables dev CSP relaxations |
| `NODE_OPTIONS=--no-node-snapshot` | Node | Required by isolated-vm on Node ≥ 20; set by every script and in CI |
| `PUCK_REMOTE_ARTIFACTS_DIR` | CLI | Default for `--artifacts` |

Render workers get an **empty environment**: nothing from the host process reaches them.

## Example app (`apps/host`)

| Variable | Default | Effect |
|---|---|---|
| `PORT` | `3100` | Dev/start port and default origins |
| `PUCK_REMOTE_ROOT` | `<cwd>/../..` | Repository root (artifacts, data) |
| `PUCK_REMOTE_ADMIN_ORIGINS` | `http://admin.localhost:<PORT>` | Comma-separated admin origins (`origins.admin`) |
| `PUCK_REMOTE_EDITOR_ORIGIN` | `http://127.0.0.1:3300` | The editor app's origin (`origins.editor`) |
| `PUCK_REMOTE_EDITOR_URL` | `http://127.0.0.1:3300/` | URL the admin page loads in the frame |
| `PUCK_REMOTE_ADMIN_TOKEN` | — | The example's admin secret in production (bearer or `puck_remote_token` cookie); without it, admin pages and RPCs are refused |
| `PUCK_REMOTE_MOCK_API_ORIGIN` | `http://localhost:4010` | Mock API origin |
| `PUCK_REMOTE_ALLOW_DEV_ORIGINS` | — | Lets a production build reach the mock API over http (local testing only) |
| `EVENTS_API_KEY` | a dev key | Secret bound to the mock API origin |

## Editor app (`apps/editor`)

| Variable | Default | Effect |
|---|---|---|
| `PUCK_REMOTE_ADMIN_ORIGINS` | `http://admin.localhost:3100` | Admin origins allowed to embed the editor (bridge and `frame-ancestors`), read at build and serve time |
| `PORT` | `3300` | Port of `serve.mjs` |
| `HOST` | `127.0.0.1` | Interface of `serve.mjs` |

## Mock API

| Variable | Default |
|---|---|
| `PORT` | `4010` |
| `EVENTS_API_KEY` | the same dev key |
