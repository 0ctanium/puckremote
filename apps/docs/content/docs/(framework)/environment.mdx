## Packages

| Variable | Read by | Effect |
|---|---|---|
| `NODE_ENV` | core | `production` disables dev CSP relaxations |
| `NODE_OPTIONS=--no-node-snapshot` | Node | Required by isolated-vm on Node ≥ 20; set by every script and in CI |
| `PUCK_REMOTE_ARTIFACTS_DIR` | CLI | Default for `--artifacts` |

Render workers get an **empty environment**: nothing from the host process reaches them.

## Example app (`apps/host`)

| Variable | Default | Effect |
|---|---|---|
| `PORT` | `3100` | Dev/start port and default origins |
| `PUCK_REMOTE_ROOT` | `<cwd>/../..` | Repository root (artifacts, data) |
| `PUCK_REMOTE_ADMIN_ORIGINS` | `http://admin.localhost:<PORT>` | Comma-separated host (admin) origins (`origins.host`) |
| `PUCK_REMOTE_EDITOR_ORIGIN` | `http://127.0.0.1:<PORT>` | The editor's origin (`origins.editor`); this app serves its editor page there |
| `PUCK_REMOTE_EDITOR_URL` | `<editor origin>/` | URL the admin page loads in the frame |
| `PUCK_REMOTE_MOCK_API_ORIGIN` | `http://localhost:4010` | Mock API origin |
| `PUCK_REMOTE_ALLOW_DEV_ORIGINS` | — | Lets a production build reach the mock API over http (local testing only) |
| `EVENTS_API_KEY` | a dev key | Secret bound to the mock API origin |

The example has **no auth**: its admin page and server actions are open. Add your own session
check in a real app.
