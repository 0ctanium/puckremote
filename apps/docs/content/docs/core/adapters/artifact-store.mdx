## `@puck-remote/artifacts-fs`

The default store, on the local filesystem. Suits a single server.

```npm
npm install @puck-remote/artifacts-fs
```

```ts
import { fsArtifactStore } from '@puck-remote/artifacts-fs';

artifacts: fsArtifactStore({ dir: path.join(process.cwd(), 'artifacts') }),
```

<TypeTable type={{ dir: { description: "Directory holding one folder per artifact and current.json.", type: 'string', required: true } }} />

```files
artifacts
├── current.json
├── 1d361ac2d6ec…
│   ├── manifest.json
│   ├── bundle.js
│   ├── bundle.browser.js
│   ├── assets
│   └── pages
└── e1cf82a1deba…
```

- **Ids are content hashes** ([D-0206](/docs/internal/decisions#D-0206)): sha256 over the sorted lines
  `<path>\0<sha256(file)>\n` of every file, in full hex (`artifactHash(files)` computes it). The
  same files always get the same id; writing them again returns the existing artifact.
- Artifacts are written to a temporary directory, then renamed: a half-written one is never
  visible. Existing artifacts are never overwritten.
- `current.json` (`{"id": "…"}`) is replaced atomically (temp file + rename).
- `watch` reports pointer changes from a directory watcher, so the host switches within ~100 ms.
- Reads resolve symlinks and refuse anything outside the artifact directory.

## Writing your own

For serverless or several instances, use a shared store (S3, a database…). Ids are yours to
choose ([D-0189](/docs/internal/decisions#D-0189)): content hashes, counters, database keys. The core treats
them as opaque strings and only requires `[A-Za-z0-9._-]{1,128}`, because they appear in URLs.

```ts
import type { ArtifactStore } from '@puck-remote/sdk/host';
```

<TypeTable
  type={{
    readPointer: { description: "Current artifact id, or null if nothing was published.", type: '() => Promise<string | null>', required: true },
    writePointer: { description: "Atomically switch the current artifact (going live, rollback). Refuse unknown ids.", type: '(id: string) => Promise<void>', required: true },
    list: { description: "All stored artifact ids.", type: '() => Promise<string[]>', required: true },
    readFile: { description: "Bytes of a file of an artifact, or null.", type: '(id: string, path: string) => Promise<Uint8Array | null>', required: true },
    writeArtifact: { description: "Store a complete artifact and return its id; must not become visible until fully written. Stored artifacts never change.", type: '(files: Record<string, Uint8Array>) => Promise<string>', required: true },
    watch: { description: "Optional change feed for the pointer. Without it the host polls readPointer every artifactPollMs.", type: '(onChange: () => void) => () => void' },
  }}
/>

The store only moves bytes: the host validates the manifest and verifies every file's hash
(pages included), and keeps serving the previous artifact if anything is wrong. Paths are
relative POSIX paths already validated by the host; still refuse escapes. Check your store with
[`artifactStoreContract`](/docs/core/adapters/testing).
