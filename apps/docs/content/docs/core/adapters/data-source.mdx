---
title: Data source
description: Answer the find, findByID and global queries of blocks from your CMS, database or API.
---

A data source declares **which collections and fields themes may reach**, and implements storage.
The engine enforces the declared policy before and after calling you.

```ts title="src/cms.ts"
import { defineCollection, defineDataSource, defineGlobal } from '@puck-remote/sdk/host';

export const myCms = () =>
  defineDataSource({
    name: 'my-cms',
    collections: {
      posts: defineCollection<Post>()({
        fields: {
          title: { type: 'text' },                         // all operators, sortable
          slug: { type: 'text', filter: ['equals', 'in'] },
          excerpt: { type: 'text', filter: false, sort: false },
          author: { type: 'relation', to: 'authors' },     // populated docs use the authors policy
        },
        limits: { default: 10, max: 12, maxDepth: 1 },
        tags: ['posts'],
        find: async (query, ctx) => ({ docs, totalDocs }),
        findByID: async (id, { select, depth }, ctx) => doc, // optional
      }),
    },
    globals: {
      site: defineGlobal<Site>()({ fields: { tagline: { type: 'text' } }, get: async (ctx) => site }),
    },
    subscribe: (onChange) => {
      // call onChange(['posts']) when content changes, to invalidate cached results
      return () => {};
    },
  });
```

  type={{

    'query.depth': { description: "Relation population depth, already clamped.", type: 'number' },
    'ctx.mode': { description: "'draft' for editor requests, 'public' otherwise. Decided by the host; you decide what draft means (e.g. include unpublished documents).", type: "'public' | 'draft'" },
    'ctx.locale': { description: "Requested locale.", type: 'string' },
    'ctx.signal': { description: "Aborted when the page's data deadline passes.", type: 'AbortSignal' },
  }}
/>

You don't need to filter fields in your output: the engine projects results to the declared
fields, including populated relations. Draft results are never cached.

## `@puck-remote/source-mock`

An in-memory example (posts, authors, a `site` global) loaded from JSON. Useful for demos and tests.

```ts
import { mockCms } from '@puck-remote/source-mock';

source: mockCms({ dataFile: path.join(process.cwd(), 'data/cms.json') }),
```
