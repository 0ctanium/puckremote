---
title: Contract tests
description: Check your own artifact store with the same test suite the built-in one passes.
---

`@puck-remote/core/testing` exports a vitest suite for the storage contract.

```ts title="my-store.test.ts"
import { artifactStoreContract } from '@puck-remote/core/testing';

artifactStoreContract('s3', async () => s3ArtifactStore({ bucket: await freshBucket() }));
```

The factory must return a **fresh, empty** store.

| Suite | Checks |
|---|---|
| `artifactStoreContract(name, make)` | Starts empty; `writeArtifact` returns a URL-safe id per artifact; files are readable by id and artifacts never change; the pointer moves and refuses unknown ids; unsafe paths never resolve. No id format is assumed |
