## `memoryCache()` (default)

```ts
import { memoryCache } from '@puck-remote/core/config';

cache: memoryCache({ maxEntries: 10_000 }),
```

<TypeTable type={{ maxEntries: { description: "Oldest entries are evicted beyond this.", type: 'number', default: '10000' } }} />

It lives in the process, so each server instance has its own. With several instances, plug a
shared store (Redis…) so invalidations reach everyone.

## What gets cached

| Query | Cached | Invalidation |
|---|---|---|
| Data source (`find`, `findByID`, `global`), public | yes | By tag, when your data source's `subscribe` reports a change |
| Data source, draft (editor) | **never** | — |
| `http()` and theme adapters | yes | After `http.cacheTtlMs` (default 30 s) |
