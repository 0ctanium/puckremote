Decisions live in `.claude/` ([D-0093](/decisions#D-0093)) and are rendered in this site under
[Decisions](/decisions) straight from those files ([D-0099](/decisions#D-0099)). The full guide is
[the ADR system guide](/decisions/ADR-SYSTEM-GUIDE).

```
.claude/
├── ADR-SYSTEM-GUIDE.md      the guide
├── adr-index.toml           master index (managed by pnpm adr)
├── adr-helper.mjs           the pnpm adr CLI
├── templates/               branch-adr, feature, chore, research
├── branches/<type>/<slug>.md          ADRs for in-progress work
└── merged/<YYYY-MM>/<type>-<slug>.md  archived ADRs
```

## Concepts

- **ADR**: one Markdown file per unit of work (branch), using the template sections (Meta,
  Problem Statement, Decisions, Decision Record, Implementation, Investigation Notes, Challenges,
  Impact, QA, Outcome, Tags).
- **Decision**: one indexed entry with a global ID `D-NNNN`, an ADR, a date, tags, a **provenance**
  and a **status**. The ADR's Decisions table between the `decisions:start`/`decisions:end`
  markers is managed by the CLI.

| Provenance | Meaning | Initial status |
|---|---|---|
| `user` | The human stated it | `accepted` |
| `user-approved-plan` | An agent proposed it; the human approved the plan | `accepted` |
| `agent-unreviewed` | An agent chose it without approval | `needs-review` |

Statuses: `accepted`, `needs-review`, `superseded`, `rejected`. Every past decision was backfilled
with its provenance ([D-0096](/decisions#D-0096)).

## CLI

| Command | Does |
|---|---|
| `pnpm adr new <type>/<slug> --title "…" [--tags a,b] [--template feature\|chore\|research]` | Create a branch ADR and index it |
| `pnpm adr decision <adr> --title "…" --provenance <p> [--tags a,b] [--supersedes D-0001]` | Add a decision (next ID) and update the ADR's table |
| `pnpm adr review <id> --status accepted\|rejected [--note "…"]` | A human confirms or rejects a `needs-review` decision |
| `pnpm adr search <term>` | Search ADRs and decisions (titles, tags, files) |
| `pnpm adr list [--needs-review\|--active\|--tag t\|--adr name\|--adrs]` | List decisions or ADRs |
| `pnpm adr show <D-id\|adr>` | Show one decision or ADR |
| `pnpm adr archive <adr>` | After merge: move to `merged/YYYY-MM/` and mark it merged |
| `pnpm adr check` | Validate files ↔ index consistency |
