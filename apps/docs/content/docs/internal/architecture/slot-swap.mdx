---
title: Slot swap
description: Turning isolate HTML into React with real Puck slots.
---

`htmlToReact(html, { nonce, slots, allowed })` uses `html-react-parser` with a `replace` callback
that only acts on `div` elements carrying `data-puck-slot`:

- the `data-nonce` must equal the render's nonce (and be non-empty);
- the name must be in `allowed` (the block's slot fields, plus `children` for the root) and in
  `slots`;
- the name must not have been swapped already.

The slot value is either Puck's slot component (a function, rendered with `createElement`) or a
React node (the root's `children`). Everything else in the HTML is parsed as-is.

Island markers (`data-puck-island`) follow the same rules: the render's nonce, a key the block
reported, and at most one swap per key. They are replaced by `islands.render(key)`, which is a
`<ThemeIsland>` on public pages ([islands](/docs/internal/architecture/islands)).

On the theme side, `<Slot name>` reads the nonce from module state set by `__render` for the
duration of one render call (`sdk/src/state.ts`), so it can only produce the right nonce while the
host is rendering that block.

The nonce is 128 bits from `crypto.randomBytes`, fresh per render call. Only the public renderer
(`puck-rsc.tsx`) swaps markers: in the editor, blocks render as real components and `<Slot>`
reads Puck's slot components from `SlotContext` instead of producing a marker.
